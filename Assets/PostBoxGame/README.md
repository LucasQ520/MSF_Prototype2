# Post Box — playable prototype

Open `Assets/PostBoxGame/Scenes/PostBox.unity` in Unity 6000.0.59f2 and press Play. The game opens at calibration. If the scene needs rebuilding, use **PostBox Game > Build / Rebuild Prototype**. This creates the scene, default data asset, and build entry without changing the sample scene.

## Marker

Use a vivid blue or green matte card in even light. Select the camera, hold the card in the yellow target at a comfortable distance, and press **Calibrate**. The camera samples its color and visible size. Move the card left/right/up/down to tilt the post box body; bring it closer until the top says **SLOT OPEN**, then move it back until it says **SLOT CLOSED**. A lost marker pauses the run until tracking resumes. Recalibrate by restarting Play mode. The camera preview appears only on the calibration screen.

## Play

Mail falls into the top of your body. Tilt to slide the active piece around the 8×6 interior, press **R** to rotate, choose a route with **1–6** or the route buttons, then press **Space** to settle it. **Tab** opens the attached resident card. The postal carrier collects after four minutes. Express mail must be settled within 25 seconds. Charles's mail is held; Ramiro's old address is forwarded to his current route; mismatched addresses and Jesse Fuchs's mail are returned.

## Debug and accessibility

**F2** toggles keyboard body control. Arrow keys tilt; holding Left Shift closes the slot. **F1** shows the debug overlay. This fallback emulates body motion and does not move a cursor.

## Data

`Assets/PostBoxGame/Resources/PostBoxConfig.asset` is created automatically by the editor if absent. Edit resident names, addresses, mail footprints/values, grid size, arrival intervals, and run duration there. The editor menu rebuilds the scene and preserves an existing configuration.

## Current limitations

Graphics and simple sound cues are generated by code, without external assets. Webcam tracking uses a sampled color region; clutter or lighting close to the marker color can confuse it. The grid currently moves only the newest mail piece; settled pieces cannot be rearranged. Keyboard input chooses routes because marker orientation is intentionally optional.
